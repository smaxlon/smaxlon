### Building in the open

I'm working on **[Martenwatch](https://github.com/smaxlon/martenwatch)**, an open-source research prototype for exploring how AI agent actions can be checked, reviewed and traced.

| Focus | What I'm exploring |
|:--|:--|
| **Agent safety** | Server-side policy checks and human review for simulated actions |
| **Reliability** | Recovery, retries and duplicate execution scenarios |
| **Observability** | Traces, metrics and reproducible local experiments |
| **Open source** | Clear documentation, tests and honest technical limits |
